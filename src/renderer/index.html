      AcoustID Recognition & API Key Setup
      1. How Acoustic Recognition Works
      Orphira calculates an acoustic fingerprint of your audio tracks locally using the fpcalc tool. Only fingerprint vectors and track duration are sent to AcoustID to find missing metadata—your audio files are NEVER uploaded to the internet.
      2. Personal API Key Required
      Orphira does not include or use a built-in AcoustID key. Acoustic recognition remains disabled until you enter your own AcoustID Client API Key in Settings.
      3. How to Register Your Free Key
      + Free & no credit card required
      + Your key is stored in Orphira settings
      1. Sign in to AcoustID using your MusicBrainz account.
      2. Go to the Application Registration page:
      https://acoustid.org/new-app
      3. Enter any Application Name (e.g., Orphira Player) and submit.
      4. Copy your API Key (Client API Key) and paste it into the Settings input.
